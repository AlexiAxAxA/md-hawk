# Хранение состояния

## Данные и границы

`electron/store.cjs` — единственный владелец `state.json` и `state.json.bak` в Electron userData. Версия схемы — 3; неизвестная версия не перезаписывается молча.

Settings: theme, rememberPosition, fontSize (8–40), columnWidth (560–1100), language (16 кодов), customColors, fontFamily, lineHeight (1.2–2.4), paragraphSpacing (0–40). Space: id, name, documentIds; группы ссылаются на историю и сохраняют порядок выбранных документов. DocumentRecord: id, нормализованный path, title, preview, lastOpened, pinned, position и bookmarks. Position: text, before, after, heading, headingIndex, offset и fraction. Bookmark: id, name, position. Полный текст документа в состоянии не хранится.

## Запись и восстановление

Мутация клонирует состояние, изменяет копию и синхронно записывает временный файл с fsync. Корректный предыдущий основной файл копируется в `.bak`, затем временный переименовывается в основной. Только после успешной записи меняется состояние в памяти. Записи сериализуются циклом событий main; параллельная запись сторонними процессами не поддерживается.

Если основной файл повреждён, используется резервный с предупреждением. Если обе копии повреждены, они сохраняются и новые записи блокируются. Явное восстановление архивирует копии с `.corrupt-<timestamp>` и создаёт новую историю. Резервная копия может не содержать последнего изменения.

Удаление истории не удаляет исходный документ и убирает его id из пространств. Удаление пространства не изменяет историю или исходники. Переуказание с объединением дублей заменяет ссылки пространств на сохранённый id. Закладки сохраняются независимо от настройки автоматических позиций. Выключение rememberPosition оставляет прежнюю позицию в JSON, но запрещает дальнейшие автосохранения; renderer открывает файл с начала до повторного включения.

## Проверки и будущая работа

Core-тесты подтверждают перезапуск, отсутствие дублей, закрепление, настройки, закладки, режим без запоминания, перемещение и повреждение копий. E2E проверяют данные через установленное приложение. Результаты: [verification.md](../verification.md); требования P2/P4: [plan.md](../plan.md).

Состояние v1 автоматически преобразуется в v2 в памяти: прежние документы, позиции, закладки и настройки сохраняются, добавляются language=ru и spaces=[]. Затем применяются значения v3; следующая мутация записывает v3 атомарно. Проверена миграция и сохранение групп/языка после перезапуска. Неизвестные версии не перезаписываются. Синхронизация и перенос между ОС за границами v1, см. [known-issues.md](../known-issues.md).

## Настройки v3

Миграция v1/v2 добавляет недостающие параметры, сохраняя идентичность документов, позиции, закладки, закрепления и пространства. Цвета принимаются только как #rrggbb для известных токенов и шести тем. Сброс чтения обновляет Settings; не вызывает Store.reset и сохраняет выбранный язык. Исходные файлы не изменяются. Начальный язык установки применяется лишь к новому профилю. Проверки миграции, сброса и недопустимых значений: tests/core.test.cjs; [настройки](preferences.md).
