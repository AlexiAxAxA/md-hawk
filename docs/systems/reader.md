# Интерфейс и чтение

## Модули и взаимодействие

`src/App.tsx` управляет вкладками, домашним экраном, перетаскиванием, горячими клавишами и очередью настроек. `Home.tsx` показывает закреплённые/недавние файлы, поиск и последний документ. `Settings.tsx` и `styles.css` задают шесть тем, шрифт и ширину. `Reader.tsx` отвечает за прокрутку, оглавление, закладки, поиск и позицию. IPC описан в `src/types.ts` и [оболочке](desktop.md).

Вкладки перемещаются Pointer Events с захватом указателя после порога 5 px: preview скользит горизонтально по строке, выделяется тенью, цветная метка показывает границу вставки. Положение курсора относительно центра соседней вкладки выбирает сторону. Escape/pointercancel убирает preview; отпускание меняет только порядок, не активный документ. Нативная плавающая drag-картинка не создаётся; file-drop остаётся самостоятельным действием. Alt+←/→ на кнопке вкладки переставляет её с клавиатуры. Порядок вкладок живёт в текущей сессии.

Домашняя панель использует ограниченный по высоте flex-layout и CSS container units для размеров карточки. При уменьшении окна сжимаются отступы/иллюстрации и убираются второстепенные подсказки; кнопки открытия/продолжения остаются доступными. Правая панель не прокручивается; библиотека использует overflow-y:auto, без лишнего переполнения пустого состояния. Большой список сохраняет прокрутку. При минимальной высоте строки сокращаются до названия и кнопок закрепления/удаления; полный путь доступен во всплывающей подсказке.

`Spaces.tsx` создаёт, переименовывает, удаляет и открывает группы документов из истории; можно сохранить текущие вкладки. `i18n.ts` и Settings переключают русский/английский интерфейс с сохранением выбора, включая aria-подписи. Текст файла не переводится. Подпись «Ваше пространство для чтения» удалена из шапки.

Повторное открытие активирует существующую вкладку. Открытые вкладки сохраняют место в сессии даже без автосохранения; закрытый и заново открытый файл в этом режиме начинается с нуля. Горячие клавиши используют Ctrl/Cmd: O/F/D/W и запятую.

## Markdown и навигация

`src/markdown.tsx`: react-markdown + remark-gfm/math → rehype-raw/sanitize → KaTeX → подсветка кода → уникальные якоря → поиск. Поддержаны заголовки, списки, цитаты, таблицы, задачи, изображения, код, сноски, формулы и Mermaid. Неверная формула/диаграмма показывает локальную ошибку, остальной текст остаётся читаемым.

Mermaid рисуется последовательно в strict-режиме без HTML labels; цвета берутся из CSS-палитры темы. Монохромные диаграммы дополнительно обесцвечиваются. Поиск создаёт mark-узлы в дереве, без ручного изменения React DOM; максимум 2000 совпадений. Формулы и SVG не входят в поиск.

Оглавление, якоря и сноски используют безопасный поиск id; повторяющиеся заголовки имеют суффиксы. Относительная MD-ссылка открывает вкладку и учитывает фрагмент; внешние ссылки идут в браузер. Картинки разрешаются относительно документа или загружаются по HTTPS.

## PDF и Word

`PdfReader.tsx` использует PDF.js с отдельным локальным worker. Одновременно рисуется одна страница canvas с настоящим текстовым слоем; доступны номер страницы, кнопки перехода, масштаб и поиск по извлечённому тексту. Закладки используют общую модель Store. Автоматическая позиция PDF хранит номер страницы (`pdf:page:N`), а не смещение внутри страницы. Документные скрипты, формы и link annotations не подключены.

`WordMarkdown` в `markdown.tsx` лениво загружает Mammoth и преобразует DOCX в HTML. Внешние файлы и встроенные style maps отключены; результат очищается общей цепочкой Markdown. Встроенные PNG/JPEG/GIF/WebP преобразуются в ограниченные data-src. Reader отслеживает появление преобразованного содержимого и восстанавливает блоковую позицию. Проверены заголовки, жирный текст, таблица, встроенная картинка и очистка опасной ссылки. Точное воспроизведение Word-вёрстки не обещается.

## Позиция и закладки

`src/position.ts` сохраняет блок, соседний текст, ближайший заголовок и номер повторения, долю смещения внутри блока и процент. Восстановление использует текст с контекстом, затем заголовок, затем процент. При приблизительном восстановлении появляется уведомление.

ResizeObserver и текущая привязка удерживают место после изменения окна, темы, шрифта/колонки и загрузки ресурсов. Нулевая позиция возвращается точно к началу. Одинаковые абзацы различаются по контексту, заголовку и прежнему проценту.

Позиция сохраняется через 450 мс после прокрутки, при переключении и закрытии. Закладка получает имя из блока; доступно переименование/переход/удаление независимо от автосохранения. Данные находятся в [Store](storage.md).

## Копирование и выделение строк

CodeBlock.tsx добавляет кнопку копирования исходного текста с переводимым статусом. Ограниченный copyText IPC пишет строку до 20 МиБ; прочитать буфер из документа нельзя. LineSelection.tsx использует Chromium caretRangeFromPoint и Selection.modify: правое поле со стрелкой выбирает визуальную строку, перетаскивание объединяет диапазон строк. Обычное выделение мышью и Ctrl/Cmd+C остаются доступными. Работает в Markdown/DOCX; PDF использует свой текстовый слой. Цвета Mermaid пересчитываются при смене пользовательской палитры. Типографика — [настройки](preferences.md). Проверка реального буфера/выделения и перезапуска: tests/e2e/reader.spec.ts, P15–P17.
