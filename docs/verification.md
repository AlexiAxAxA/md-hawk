# Проверки MD Hawk

Первоначальная проверка версии 1.0.0: 2026-10-04. Среда: Windows x64 (10.0.26300), Node 24.14.0, npm 11.9.0, Electron 44.5.1. Полные настольные проверки выполняются вне ограниченной среды Codex; contextIsolation/sandbox приложения остаются включёнными. Тестовые профили и документы находятся в `.verification`, отдельно от пользовательской истории.

## Логика и сборка

`npm test`: 12/12 пройдено (6 Node core + 6 Vitest). Подтверждены история без дублей, сохранность исходных файлов, закрепление/настройки/закладки после перезапуска, выключенное запоминание, резервная копия, блокировка при повреждении обеих копий, архивирование, перемещение, проверка путей и внешних URL. Позиционные тесты проверяют контекст, повторяющийся текст, одинаковые заголовки, нулевой scrollTop и fallback.

`npm run build`: TypeScript и Vite успешно. Vite предупреждает о некоторых чанках больше 500 КБ; Mermaid загружается динамически, виртуализации больших документов пока нет.

`npm audit --json --cache .verification/npm-cache`: 0 уязвимостей на дату проверки; отчёт `.verification/audit.json`. Это результат проверки известных уязвимостей зависимостей, а не общая гарантия безопасности. Override @electron/get >=5.1 устранил устаревшую транзитивную цепочку загрузчика; Windows-упаковка после этого выполнена успешно.

## Исправления, найденные проверками

- Нулевая позиция больше не обрезает верхний отступ на 19 px.
- Одинаковые абзацы под разными заголовками различаются при восстановлении.
- ResizeObserver учитывает текущую привязку после пользовательской прокрутки.
- Закодированные UNC/сетевые пути отклоняются после URL-декодирования.
- Mermaid использует палитру каждой из шести тем, включая сепию и монохромные темы.
- Стандартная Windows-ассоциация заменена регистрацией Open With без назначения по умолчанию.
- Тесты закрывают настоящее окно и ожидают flush/выход; общий лимит сценария увеличен до 120 секунд для длинного сценария перезапуска на этой машине.
