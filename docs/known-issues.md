# Ограничения и отложенная работа

## Границы версии 1.1

- Редактирование, экспорт, облачная синхронизация и автообновления отложены: не входят в задачу. Возврат — отдельный запрос пользователя.
- Пути и история локальны для устройства; перенос состояния между ОС не является синхронизацией.
- Автоматический поиск файла после произвольного перемещения отсутствует; используется «Указать новое расположение».
- macOS/Linux: сборка и запуск требуют соответствующих систем. До проверки статус неподтверждённый.
- Подпись Windows и нотарификация macOS требуют сертификатов владельца; без них сборки не объявляются подписанными.
- Текущая Windows-сборка не подписана (Authenticode: NotSigned). Windows может показать предупреждение при скачивании на другом компьютере.
- Документы: до 20 МиБ, UTF-8 или UTF-16 с BOM; изображения до 30 МиБ. Большие документы не виртуализируются, производительность на предельных размерах не подтверждена. Возврат к оптимизации — замеры на реальных больших документах.
- Изменение файла сторонним редактором не обновляет открытую вкладку вживую. Повторное открытие читает новую версию. Live reload отложен до отдельной потребности; позиция уже учитывает изменённый текст.
- Поиск подсвечивает до 2000 совпадений; текст формул и диаграмм не включается. Расширение поиска — при отдельном запросе.
- HTTPS-картинки используют сеть, если они есть в документе. HTTP-картинки и сетевые пути внутри Markdown отклоняются; внешние HTTP/HTTPS-ссылки открываются в браузере.
- При аварийном завершении последняя прокрутка после отложенного сохранения может потеряться. При обычном закрытии используется подтверждение flush, с тайм-аутом 5 секунд для неотвечающего renderer.

- Word: поддерживается DOCX; старый бинарный DOC требует конвертации. Mammoth передаёт содержимое, а не точную страничную вёрстку Word: сложные фигуры, колонтитулы и геометрия страниц могут отличаться. Расширение поддержки — по конкретным проблемным документам.
- PDF: до 5000 страниц; сохраняется страница, не прокрутка внутри страницы. Нет ввода пароля, OCR сканов и кликабельного слоя PDF-аннотаций. WASM-декодеры отключены; сложные изображения/цветовые профили не проверены. Возврат — запрос на соответствующую функцию и контрольные документы.
- Перестановка вкладок сохраняется только в текущей сессии. Для постоянных групп используется «Мои пространства»; прошлые вкладки по-прежнему не восстанавливаются при обычном запуске.
- Кэш пяти файлов и ленивые загрузки PDF/Word уменьшают повторное чтение и стартовую загрузку новых модулей. Общий процент ускорения не измерялся; крупные предельные документы требуют отдельных замеров.

## Проверки

Выполненные проверки и исправленные дефекты: [verification.md](verification.md). Текущий статус требований: [plan.md](plan.md). macOS/Linux, подпись и указанные стресс-сценарии не входят в подтверждённую область Windows-проверки.

## Локализация и оформление 1.2

- 16 словарей интерфейса покрывают известные строки; переводы не проходили редактуру носителями. Редкие диагностические ошибки валидации IPC остаются на русском. Корректировки переводов принимаются через GitHub Issues.
- Установщик предлагает 15 языков: NSIS не содержит Bengali. বাংলা можно выбрать в настройках. Portable ориентируется на язык ОС; веб-страница GitHub не переводится самим приложением.
- Шрифт, интервалы и правое поле выделения относятся к Markdown/DOCX. PDF сохраняет оригинальную геометрию страницы и собственный текстовый слой; цвета страницы зависят от базовой темы, не всех пользовательских токенов.
