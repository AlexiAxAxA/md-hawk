# Version history

## 1.2.0 — 2026-10-05

One-click code copying, whole-line selection from the right margin, custom theme colours and typography, 8–40 px text, safe reading-settings reset, and 16 interface languages. Windows installer language selection. First public GNU GPLv3-or-later release.

## 1.1.2 — 2026-10-05

Adaptive home screen: compact windows stay usable without redundant scrollbars; long document lists still scroll.

## 1.1.1 — 2026-10-05

Tabs slide along their row with a shadow and insertion marker. Escape cancels a move.

## 1.1.0 — 2026-10-05

PDF and Word DOCX reading, document spaces, English interface, draggable tabs, reopening cache and improved window sizing.

## 1.0.0 — 2026-10-04

Markdown reader with history, pins, tabs, saved reading positions, manual bookmarks, six themes, contents, links, formulas and diagrams.

Windows releases are verified. macOS/Linux remain unverified; see the [README](README.md) for current availability.
